## Change and diagnosis

ShellCheck v0.10.0 on `deploy/smoke.sh` exited 1 with SC2086 on the unquoted
`POSTGRES_PORT` export and SC1007 on the implicit empty `CDPATH` assignment.
[Before output](evidence/db-013/before.txt) captures the command and diagnostics.
The two syntactic causes are directly identified by the linter, so runtime
hypothesis generation and instrumentation were unnecessary. The linter itself
provides the regression check; no additional test harness was added.

Quote the export and spell the empty value as `CDPATH=''`. Extend workflow
lint to the deployment and package scripts. Syntax checks invoke Bash or `sh`
once for each file: additional arguments to `bash -n file ...` are script
arguments, so the old single invocation did not parse every listed file.
ShellCheck still uses each script's shebang. This explicitly covers seven
operational scripts; historical evidence scripts remain outside the scope.

## Impact and rollback

No application API, authentication, transport, migration or security policy
changes. The script uses the same disposable database/project and removes only
its test volume. Test passwords are generated in memory, never recorded, and
replacement redaction is applied before writing captured smoke output. The
expanded lint adds build-host work only; no device allocation, runtime
dependency, flash write, root requirement or measured performance claim is
introduced. New CI scope can reject future shell mistakes before merge.

Rollback is a reviewed revert of the DB-013 commits through an isolated feature
branch and Draft PR into `develop`, followed by human manual merge. It restores
the previous script/lint scope without changing databases, credentials or device
state. Do not merge, self-approve or enable auto-merge as part of this change.
